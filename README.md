# Hammad Ali Haider — Academic Portfolio

A dependency-free static research portfolio designed for free hosting on GitHub Pages.

## Local preview
Open `index.html` in a browser, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Free deployment
This repository is named `hammadhaideer.github.io`, so GitHub Pages can publish it at `https://hammadhaideer.github.io`.

## Before publishing
- Replace the initials panel with a professional headshot if desired.
- Add a public PDF CV only if you are comfortable publishing the contact details it contains.
- Add Google Scholar once the profile is ready.
